# Routed Qwen activation clip: a small family bound

[Kelana's shared-input experiment](../../kelana/research/moe/shared-activation/README.md) tests one activation code reused by all eight selected experts and both gate/up products, a boundary the current HIP grouped expert runtime already shares. It uses sixteen original BF16 layer-0 experts, sixty-four synthetic train and sixty-four held inputs, random eight-of-sixteen routes, and measures the complete weighted post-SwiGLU/down output. It is not a real-route capture or a whole-model result.

With signed four-bit activations, train-selected .75-of-maximum clipping improves held output RMS from .20237 to .15841; even a free per-token oracle choosing among four shared clips only reaches .15083. With signed eight-bit activations, max-based quantization scores .01141, and all sixty-four held tokens select it even when the oracle reads the original composed output. The four-candidate oracle is a checked bound for this **finite scalar-clip family**, not for learned quantizers or expert-specific codes. A real selector would need candidate preparation and expert response work that the oracle's quality comparison does not charge as elapsed time. There was no GPU measurement or runtime change.

A Q4 input payload is half Q8's bytes, but it cannot be treated as a traffic gain until a native packed expert consumer avoids expansion and preserves useful language quality. The dense sub-bit pilot's complete-model quality failures apply as a warning here: a layer-0 synthetic RMS gain cannot pick the serving numerical map. Capture actual router choices and producer activations next; compare fresh held language quality and matched-rate alternatives before any Q4 engine work. Q8 scalar clipping has no measured headroom in the tested input family.

The source, proof boundary and [source/weight-hashed CPU receipt](../../data/qwen-moe/shared-activation/receipt-128.json) are in the Kelana report. The first 24-sample exploratory receipt is retained with its invalid oracle-SSE diagnostic called out there.
