# Exact ordinary Q8 code pages: a paid rate point, not a native shortcut

The installed Qwen3.6-35B-A3B UD-Q4_K_M nonembedding, nonexpert Q8_0 bank has 250 tensors, 43,909,120 blocks, 1,405,091,840 signed code bytes and 87,818,240 FP16 scale bytes. Its native one-row Q8 phase is 8.333 ms/token in the counter-free depth-1024 trace. Can lossless *independently addressable* compression of the **actual code image**, without changing the decoded weights, remove a meaningful fraction of the complete one-read model stream? Unlike a narrow signed-width recode, this experiment does not demand that all 32 codes in a block fit seven bits.

Each tensor's 32 code bytes per Q8_0 block are concatenated in installed block order. Every 16,384-byte page (512 complete blocks, shorter final page allowed) is stored as zlib level 1 or raw, whichever is shorter. A four-byte page count and four-byte tagged length per page delimit independently decompressible pages; there is no free directory or shared dictionary. The original scale words are saved verbatim as a separate, checked per-tensor scale image. All 85,760 pages are zlib-coded. The reader in `tools/qwen-moe/q8_code_entropy.py` inflates every saved page, interleaves it with the saved scales and checks the SHA-256 of **each entire original tensor payload**. This establishes a lossless storage coordinate for the whole ordinary Q8 bank. It does not establish identical FP32 execution of a new decoder or change any GGUF tensor in the selected runtime.

| Complete ordinary Q8 bank component | Bytes |
| --- | ---: |
| Original codes | 1,405,091,840 |
| Original FP16 scales | 87,818,240 |
| Original total | 1,492,910,080 |
| **Saved independently addressable code pages, including directory** | **1,346,520,632** |
| Saved unchanged scales | 87,818,240 |
| **Saved complete Q8 bank** | **1,434,338,872** |
| **Exact saving** | **58,571,208 (3.9233% of Q8 bank; 2.23027% of conditional complete one-read weights/token)** |

The code-page saving is 4.16850% of original code bytes. The 503.316-MB `attn_qkv` code group contributes 21.700 MB; `attn_gate` and `ssm_out` contribute 10.028 and 10.011 MB. These are ordinary projection images, not the routed expert bank. Against a *free* per-tensor IID-byte entropy coder with its probability model and decoding cost uncharged, the code-image saving would be 67,819,704 bytes, or only 9,248,496 more than the actual pages (0.35216% of complete one-read bytes). This is a ceiling **within the per-tensor IID symbol model**, not an information-theoretic bound on block-context, producer-conditioned, or changed-weight representations. Zero codes are 12,955,857/1,405,091,840 bytes; this page result is not the previous zero-*row* removal and cannot be added to that overlapping hypothetical without re-encoding.

The installed single-token conditional one-read stream is 2,626,187,904 bytes, of which 611,516,416 are routed expert images. Its 242-GB/s traffic comparator would assign just **0.242 ms/token** to the removed 58.571 MB if those bytes actually reached DRAM once and the decoder were free. That is not a wall-clock bound or native gain: Q8 pages require an inflation step, random block access either inflates a 16-KiB page or retains a decompressed cache, and GPU zlib is not the current packed Q8 consumer. Even free elimination of these bytes would leave most of the 8.333-ms traced Q8 phase and 20.398-ms profiled device sum untouched. The data therefore support an exact paid-rate construction but **reject porting zlib pages as the next decode speedup**. Measure unprofiled ordinary Q8 physical transactions and per-call timing with complete heads, then seek a code coordinate consumed directly by the native integer dots or a changed image justified by held complete-model quality. The page coder is a control against which a new direct-consumer representation must earn its boundary cost.

## Reproduction and custody

`python3 tools/qwen-moe/q8_code_entropy.py --first 0 --count 250` saves 250 `.pages`, 250 `.scales`, and per-tensor JSON receipts under `../../data/qwen-moe/q8-code-pages/`; `--summarize` hashes all saved sidecars and receipts. Each per-tensor receipt hashes original tensor payload, reconstructed code, saved page/scale images, source and inventory. [Aggregate receipt](../../data/qwen-moe/q8-code-pages/receipt.json) includes all tensor hashes; final-source run log is `../../data/qwen-moe/q8-code-pages-run-final-3.log`. `traffic.json` owns the GGUF header hash and tensor offsets; the verified GGUF acquisition receipt fixes complete upstream SHA-256 `ac0e2c1189e055faa36eff361580e79c5bd6f8e76bffb4ce547f167d53e31a61`. The script uses CPU and no GPU lock; model, native executable and resident service were untouched. Storage is 1.434 GB for the complete measured Q8 sidecars in the existing Qwen data directory, not Git. The experiment scores **exact storage/rate only**; no native page-decoder latency, full-head numerical acceptance, language-quality change or TPS was claimed.
