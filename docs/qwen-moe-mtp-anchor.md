# Serial-anchor test of the long Qwen target width fork

The [long no-cut target replay](qwen-moe-mtp-fork.md) first changes all 248,320 logits at row 12 with width four, regardless of offset. This intervention asks whether the preceding *multirow replay calls* are necessary for that fork. It does not attempt to repair the Q4 MTP default.

The same packaged `81326f7` target and pinned GGUF generate sixteen plain greedy tokens, then reset state and replay the identical prompt. The control replays all sixteen tokens one by one; it matches the plain full-vocabulary FP32 bits on rows 0–16. The intervention likewise replays rows 1–11 **one at a time**, checking every full vocabulary row against plain (all equal), then sends its **first** four-token call starting with generated token 12. Its first result at row 12 changes **248,320/248,320** logit bits (max absolute difference 1.1809175), and rows 13–16 also change. All sixteen generated token IDs match the preceding fused panel. That panel's width-four uninterrupted replay also first forks at row 12. The only added intervention is that no multirow call precedes this first divergent width-four call.

This rejects *accumulated earlier multirow calls* as a necessary condition for the row-12 fork. It does **not** prove hidden recurrent state identity from matching logits, identify the first divergent layer, or establish that the differing row is caused by its own token rather than another row in the same causal batch or by graph buffer reuse. Width eight already forks at row 1. The next useful test is a no-cut, side-band capture of selected state and layer boundaries in **the first width-four call at row 12 after the eleven exact serial rows**, compared with a singleton call at that same state. Avoid a callback that changes graph fusion/lifetime; capture asynchronously into disjoint buffers after the graph, or instrument the kernel store. A repair then needs the complete 96-token target replay including the row-71 MTP choice and whole-model rates.

[Raw stdout, wrapper service restoration, compiled driver, source/runtime hashes, previous-panel identity and the failed initial anchor diagnostics](../../data/qwen-moe/acceptance/mtp-anchor/receipt.json) are retained. The initial two anchor attempts read `llama_get_logits_ith(ctx, -1)` after a different explicit-batch history and showed an invalid row-11 comparison; the final driver requests index 0 immediately after each singleton decode, prints all eleven controls, and only accepts the four-token result when all controls agree.
