# Gathered 31+1 changes the first recurrent row's new QKV, not its old history

The matched Qwen3.6 normal-order versus swapped-order **gathered** transition has three changed logical heads. [The full-head/state panel](qwen-moe-gdn-permutation-equiv.md) finds the first saved recurrent difference at R0 physical row 0. This CPU study separates its three saved convolution-history coordinates without changing the model, graph or selected runtime. It is independent of the [row-4 first-attention K rotation](qwen-moe-gdn-k-origin.md), the swapped row-1 empty KV cells, and the rejected direct writer's additional R1 row-source error.

The 32 logical sequences have the same preceding steps, third-step tokens, logical IDs and positions; only rows 0 and 1 of the third-step batch trade order, inducing a 31+1 native segment. `tools/qwen-moe/gdn_row0_origin.py` memory-maps the two retained 2.114-GB **gathered** post-states, parses the pinned R layout as `[32 physical rows, 8192 channels, 3 time coordinates]` and compares each coordinate bitwise with all 32 normal-order rows. The first two coordinates are the retained older convolution inputs; the third is the newly projected `qkv_mixed` in `build_conv_state`. The saved state is not a capture of the unsaved projection's input or graph evaluation order.

| Saved layer / row | Old positions 0 and 1 | Current QKV position 2 | Other physical rows |
| --- | --- | --- | --- |
| R0 / row 0 | **8,192/8,192 exact** in each; uniquely matches normal row 0 | **113/8,192 exact**, matches no complete normal row | All other 31 rows exactly equal over all three positions |
| R1 / row 0 | **8,192/8,192 exact** in each | **206/8,192 exact** | All other 31 rows exactly equal |
| R2 / row 0 | **8,192/8,192 exact** in each | **114/8,192 exact** | Rows 0 and 1 differ |

R0's changed new QKV words have **0.000300781 FP32 RMS difference** against a **2.049645 RMS** normal QKV; maximum absolute difference is **0.003171921** and the zero masks coincide. This is a small, broadly distributed numerical difference, not a displaced old-history row, an all-zero write or an entire other row's new projection. At R2, swapped physical row 1's *older two positions* each match **normal physical row 0 in all 8,192 bits**, while they match normal row 1 in only 114 bits; that is a later source-row effect separate from row 0's R0 fresh-projection difference. R0 and R1 row 1 are exactly equal between these two gathered states.

**Inference boundary:** the earliest saved row-0 difference already sits in the *fresh R0 QKV coordinate*, before convolution-state history can explain it. The Qwen graph constructs it through `build_qkvz` → `build_lora_mm(wqkv, input, wqkv_s)` → `build_conv_state` (source `src/models/qwen35moe.cpp` and `src/models/delta-net-base.cpp` in the selected llama.cpp source lineage). The [subsequent matched raw layer-zero input capture](qwen-moe-gdn-row0-source.md) compares the original complete heads and state against a no-callback graph-output probe: all 2,048 input words agree for every logical sequence across row orders, while row zero's new R0 QKV still differs in 8,079 words and its complete head/state remain equal to the original corresponding arms. Adding the graph output *does* perturb swapped row one (and only row one): it cannot be called globally transparent. The row-zero difference is thus after layer-zero input in the map-matched probe, not evidence for an embedding change. The remaining boundary is RMS norm versus Q8 projection/input coding or their graph execution; the small RMS does not make native FP32 identity. No speedup, new representation or accepted runtime change follows.
