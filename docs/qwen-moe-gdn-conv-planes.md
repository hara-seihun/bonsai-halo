# The rejected Qwen swap first corrupts old layer-1 convolution history

The retained failed 31+1 direct-GDN writer changes the first swapped full head and serialized state. [The whole-state comparison](qwen-moe-gdn-state-diff.md) first located row 1 of recurrent R layer 1, but could not distinguish old history from the new projected operand. This bitwise plane comparison does. It uses the same 2,114,206,957-byte gathered/control and rejected/default states after the swap; the selected guarded writer and model are untouched.

In installed native source `7861dc746ed49c6bec1aa2c4f4b8f25b1bf59674`, `src/models/delta-net-base.cpp:build_conv_state` reshapes a recurrent row into `[conv_kernel_size-1, conv_channels, n_seqs]`, concatenates `qkv_mixed` along the first axis, and stores a view beginning one time position later. Here the serialized R row is **3 × 8,192 FP32**; its three contiguous-in-channel coordinates after a one-token step are `[old history position 1, old history position 2, current qkv_mixed]`. Equality counts below compare the **u32 bits** of each saved float, not a tolerance or cosine.

| Saved recurrent R row 1 | first old coordinate / 8,192 | second old coordinate / 8,192 | new projected coordinate / 8,192 |
| --- | ---: | ---: | ---: |
| layer 0 | 8,192 | 8,192 | 8,192 |
| **layer 1** | **206** | **206** | **8,192** |
| layer 2 | 8,192 | 8,192 | 114 |
| every later recurrent layer (4–38) | **8,192** | **8,192** | 0–4 |

All other 31 rows reproduce **all three coordinates at all thirty recurrent layers**. Layer 1's 206 matching values per old plane are zeros in both arms; the two old planes have 7,986 changed words apiece. Its **entire newly projected input is bit-identical**. At layer 2 the old-history inputs still agree in full, but its newly projected input changes, and every later layer has the same old-history-equal/new-input-different pattern. This is a stronger localization than merely saying the first differing serialized tensor is R1: the first divergence is on the **old-history input to the layer-1 convolution-state update**, not its current QKV projection. The later newly projected differences are consistent with propagation through the changed layer-1 computation. The three-coordinate result also rejects a simple current-layer-1-projection-error explanation of this saved state. It does not say whether the bad history was read incorrectly during the 31-row graph or already differed before that call; a post-step snapshot cannot time an earlier graph write or establish the first operation.

The abstract main-state proof still stands: the direct 31-row GDN update reads and writes disjoint physical rows 1–31; the following singleton touches row 0. The history is a **different cache** from GDN's large S matrix. Copying more S rows or changing the GDN writer's row schedule cannot by itself repair these two old R1 planes. The next native test should compare R1 row 1 **before the 31-row call** in both arms, then place disjoint graph side-band reads immediately after `build_rs` of R1 and after the convolution-state copy during that same call, without callback graph cuts. If pre-call R1 agrees and the gathered/direct history read differs, inspect the allocation/lifetime alias between the new direct S destination view and the R gather/concat graph. If pre-call R1 already differs, reproduce the earlier stable 32-row call's full state, not merely its equal full heads. Keep the selected guarded fallback until all requested heads and serialized state agree.
