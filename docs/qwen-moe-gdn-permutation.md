# A stable generated Qwen batch has identity recurrent-state sources

The [split indexed-read experiment](qwen-moe-gdn-direct.md) kept a full state copy and measured a null. The [cross-CTA dependency certificate](qwen-moe-gdn-index.md) says that a fused indexed read/cache write needs the actual main source map `m[i]`: an empty hazard set is sufficient, but `n_rs == n_seqs` alone is not. The selected recurrent allocator supplies a stronger, *conditional producer invariant* for the existing 32-independent-stream generated benchmark. On each generated call after its 256-token seed, `s_copy_main[i] == rs_head+i`; therefore the set of cross-CTA hazardous source rows is empty. This advances that native experiment from an unknown source map to a specific no-main-snapshot candidate on this workload, without assuming arbitrary production requests share the invariant.

## Producer and observation

Selected on-demand native source revision `3f552c2ef572707f05746bdc84c1788792523d62`, `src/llama-memory-recurrent.cpp` SHA-256 `0c22ad19fe37bd53d8f66ec5ed1553320a0a3d4a69c38fea26e9931696f83563`, owns `find_slot` and `s_copy`. [The generated benchmark source](../tools/qwen-moe/generated_stream_j16.cpp) feeds 32 distinct sequence IDs in order `0..31`, eight initial tokens per ID, then one actual greedy token per ID in the **same order** at every generated step. All IDs have exclusive tails; this benchmark neither copies/removes IDs nor rolls state back, and Qwen uses `n_rs_seq=0`.

After a `find_slot` call, the allocator assigns each sequence its destination `d[i] = head+i`. It sets each destination cell's `src0` from its previous `src` (or from the zero row if fresh), then unconditionally sets `src=i` for every cell in `[min,max]`. The first seed starts with exclusive fresh tails, and leaves these thirty-two consecutive rows tagged `src=i`. On the following generated call, the same thirty-two exclusive tails already occupy `[head,head+32)` in the same order. No new empty tail is allocated; the reorder loop's `dst_id != src_id` branch is false for every sequence. Hence `src0=i`, and with `n_rs_seq=0`, `s_copy(i)=src0=i`. The pass again sets `src=i`. Induction proves this for every subsequent same-order single-token generated call. The allocator's optional search-head reset changes only where it starts searching for **empty** cells, not these owned tails or `min`. The hypothesis requires the complete active set and order to remain stable and no intervening cache-metadata mutation.

The [row-map replay](../tools/qwen-moe/gdn_permutation.py) models these selected metadata transitions independently of GDN arithmetic. At 32 rows it prints three consecutive identity generated maps, zero hazards; changing only the next call's first two sequence IDs gives `main=[1,0,2,...]` and hazards `[0,1]`. [CPU receipt](../../data/qwen-moe/gdn-permutation/receipt.json), SHA-256 `22a0d50900882baf74a700ec5ab6d18e925f00573e5b3f67ca336cb5b214a52c`, retains the full maps and checker hash. The replay is a small metadata witness; the invariant above comes from the selected allocator's assignment and `s_copy`, not from assuming the replay is a native trace. The original [arbitrary-order exhaustive replay](../tools/qwen-moe/gdn_index.py) proves the write/read guard. A changed order is not licensed by the identity proof, even though `n_rs == n_seqs` still holds.

## Cost and next native experiment

For this stable generated shape, the existing hazard criterion gives `H=∅` for **all thirty GDN layers**: state row indices come from the same recurrent allocator. Thus a fused indexed GDN that reads its own cache row into registers before replacing that row can avoid the gather's temporary write and GDN temporary read, **2 × 30 × 32 × 524,288 × 4 = 4,026,531,840 logical state bytes per generated step** in the declared no-extra-row schedule. It also removes thirty gather launches. This is a feasible traffic construction in the row dependency grammar, not a DRAM counter, elapsed-time estimate or proof of FP32 kernel identity. The measured 18.8–19.6 ms gather is a phase potentially removable, whereas the separately measured split `SET_ROWS` replaces it at ~22.3 ms. Direct cache addressing, device-cache behavior, synchronization and kernel resources may reverse any benefit.

Implement an opt-in fused indexed cache-write arm guarded by `n_rs==n_seqs` **and** `s_copy_main[i]==rs_head+i` for every row (or the general empty-hazard predicate); preserve the current GDN recurrence's per-element FP32 operation sequence and original zero ordering. An indexed row must be loaded completely before its CTA writes any of it. Check actual source maps at runtime, not merely sequence-count equality; the replay's two-ID swap is an immediate regression case. Compare generated complete-head logit bits and full cache state transitions with the selected path, and time combined GDN+state transfer plus whole-model generation/prompt and other batch shapes under the GPU wrapper. Do not select the branch on the CPU certificate alone. The selected runtime, resident service, model image and GPU were unchanged by this result.
