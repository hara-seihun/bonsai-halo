# Actual routed gate/up producers have no exact zero slices

The selected Qwen3.6-35B-A3B GGUF's **forty-layer, two-split actual post-attention producer capture** has no exact zero FP32 element in either disjoint 64-token prompt prefix: **0 / 5,242,880** elements per split. Each 2,048-wide producer is shared by the eight routed gate/up experts of its layer/token. Therefore all **163,840 native 32-input Q8_1 blocks per split**, or 1,310,720 routed block uses, contain a nonzero value. Even the 4-, 8- and 16-coordinate contiguous groups contain **zero** all-zero groups. In contrast, the separately captured routed post-SwiGLU *down* operands have ~1% zero elements and a few zero short groups, though no full 32-input zero blocks. Do not transfer that sparsity to the gate/up input.

The native Q8_1 rule is `d=max(abs(x))/127`, round each `x/d` to an integer code, and carry the FP16 activation scale and sum for quantized affine weight correction. Each finite nonzero 32-input block necessarily has a maximal-magnitude code of magnitude 127, so a full native block's dot **cannot be skipped** on a zero-code predicate. A source-zero 4- or 8-input group would be sufficient to erase its contribution, including the corresponding sum correction; none occurs here. This does *not* rule out a smaller subblock whose rounded codes and properly accounted affine correction happen to cancel even with nonzero FP32 inputs, or changed producer coordinates. The installed Q4_K reader has no independent four-coordinate slices in any case.

The selected gate/up bank contributes **377,487,360 conditional one-read bytes/token**, including eight of 256 experts on each of forty layers, versus 2,626,187,904 modeled whole-model bytes/token. In the declared grammar of free exact-zero tests and independently addressed weight slices of length 32 or even four producer coordinates, the saved bytes on **both observed prompt splits are zero**. Thus no native zero-activation gate/up skip is justified by this producer domain. This is an observed finite-domain result, not a universal generated-token theorem, a DRAM counter or a whole-model speed measurement. The selected runtime and service did not change.
