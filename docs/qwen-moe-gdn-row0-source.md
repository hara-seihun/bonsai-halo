# Qwen row-zero difference begins after the layer-zero input

The selected Qwen3.6-35B-A3B runtime's matched 32-sequence, three-step **gathered** experiment changes logical sequence 0's fresh recurrent R0 QKV plane when the last step swaps physical rows 0 and 1. Previously, its two old convolution planes matched exactly, while the new 8,192-wide plane differed in 8,079 FP32 words. Is the first difference already in the input to layer 0?

A two-arm probe enables the installed libllama's `llama_set_embeddings_layer_inp(ctx, 0, true)`, which marks the layer-zero input as a graph output and exports it after each decode. It uses no backend evaluation callback and retains **all 32 complete vocabulary heads and the whole serialized state** in both row orders. This is *not automatically a passive probe*: adding a graph output changes allocation lifetime, so the original normal and swapped arms are compared against the probe at every step before interpreting it.

| Comparison with original no-output arm | Complete heads, steps 0/1 | Step-2 head differences | Complete post-state |
| --- | --- | --- | --- |
| normal gathered | 0 / 0 differing words | 0 across 32 × 248,320 | bit-identical, all 2,114,206,957 bytes |
| swapped gathered | 0 / 0 differing words | logical sequence 1 alone: all 248,320 words | 57 recurrent R/S regions, physical row 1 alone; first at R2. All ten-layer KV and metadata unchanged. |

Thus this built-in output **cannot** be called a transparent observer for the whole swapped graph. But its row-zero full head and *every saved state region* reproduce the original swapped arm exactly, including the R0 new plane; the normal arm is globally exact. The row-one perturbation is excluded from the row-zero comparison rather than hidden by matching greedy IDs.

The exported layer-zero input is `[rows,2048]` FP32. On steps 0 and 1 the entire exported tensor matches between arms. On the permuted step, raw physical rows 0/1 exchange and exactly **2,039 of 2,048** input words differ at each of those two physical positions; after aligning logical sequence IDs, **all 32 × 2,048 input words are equal**, including logical sequence 0. The two original old R0 convolution planes are also 8,192/8,192 equal, but its new QKV plane still differs 8,079/8,192 words (RMS 0.0003007809, maximum 0.00317192). The same R0 values and complete row-zero output/state occur in the original no-output arms. The changed word is therefore generated **after the exported layer-zero input** in the map-matched row-zero execution, before the first saved R0 QKV plane: layer-zero RMS normalization, Q8_0 × Q8_1 projection/input coding, or their graph-lifetime execution. This is not evidence that one of those operations has a specific bug, and equal real-algebra input does not prove identical native FP32 results across row layouts.

The next native discrimination is to capture `attn_norm` and `linear_attn_qkv_mixed` in **disjoint side-band storage** without a callback or a graph output that aliases live operands, compare the same 32 full heads and 2.114-GB state in both orders, and then compare FP32 word bits. If norm is equal but QKV differs, target Q8 preparation/matvec or output destination; otherwise inspect the norm's row ownership. Row 1's missing newest K/V destination and row 4's temporal IMRoPE position are separate branches. The selected stable-32 guarded runtime is unchanged.
