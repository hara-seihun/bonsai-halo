# Old-source lifetime across segmented Qwen GDN calls

The [source-owned fanout schedule](qwen-moe-gdn-fanout.md) covers arbitrary active subsets **when their destinations and old sources are committed together**. A split call may instead require a later segment to read a state row that an earlier segment has already overwritten. This note gives a tight scratch capacity for that distinct old-snapshot contract. It does not explain the observed failed 31+1 native call: its retained trace has **zero** such rows.

## Contract and construction

Let `A` and `B` be disjoint destination sets in that order, together occupying `n` live physical slots. Every destination `d` reads its source `s(d)` from the **same pre-A snapshot** and produces `F_d(old[s(d)])`; outputs from A must be materialized before B runs, and all other live rows must remain available. `F_d` is row-local and uses its own fixed operands. Define the exposed set `E=A ∩ s(B)`, the distinct old source rows in A still needed by B. Save each old row in `E` once, before A writes, and carry the B source label to that saved row. Within A, each source in `A\E` owns its original slot and writes it last after making any fanout outputs. Slots in `A` without such source owners hold remaining A outputs. Sources in E are read from the snapshot while their original slots are free for outputs. All other A sources lie outside A and remain untouched. In B, all old sources within A are in E, while each source in B can own its original slot and write last; allocate the other B slots to remaining outputs. The two segments therefore reproduce the gathered old-snapshot map with **exactly `|E|` retained full rows**, `n` final row writes and no intermediate full-batch gather. Physical row labels change and must be carried into every consumer. Fanout inside each source/shard owner is serial; independent groups have no cross-write/source conflict.

In the grammar with independently variable full-row old values, no inverse/recomputation of an overwritten row, and arbitrary row-local transitions, `|E|` is also necessary at the A/B boundary: choose A transitions independent of the exposed old values and B transitions that reveal each of those distinct old values. The n materialized final/inactive logical rows cannot encode those additional independent values; fewer than `|E|` full-row equivalents lose one. This is a worst-case information bound for this segmented, fully materialized-row grammar, **not** an ISA-independent lower bound or a claim that the native GDN's FP32 transition is invertible/noninvertible. If B is allowed to read each exposed row before A commits, or an extra global read barrier is permitted, the domain changes and scratch can disappear. If B instead reads the *updated* A state, `E` is not an old-state obligation at all.

A two-row witness is `A={0}`, `B={1}`, `s(0)=0`, `s(1)=0`. A must publish new row 0 before B, but B still needs old row 0: one retained row is necessary in the stated grammar. A cross-segment swap, `s(0)=1`, `s(1)=0`, also requires one. By contrast, `A={1,...,31}`, `B={0}`, `s(d)=d` has `E=∅`.

## Checked finite domain and price

[`gdn_segment_lifetime.py`](../tools/qwen-moe/gdn_segment_lifetime.py) exhausts **3,754** nonempty ordered two-segment partitions and all original-source maps at two to four live rows. An independent old-snapshot reference agrees after both segments for forward and reversed group execution; 1,139 maps require no retained row, 2,423 require one and 192 require two. The checker uses a nonlinear modular row transition, asserts every read still gets the original source value and checks the final logical-to-physical labels. [The receipt](../../data/qwen-moe/gdn-segment-lifetime/receipt.json) hashes the checker and installed source bundle and binds the actual failed split's trace hash. This CPU result proves neither native FP32 bits nor full-model speed.

One Qwen state row is 524,288 FP32 elements per recurrent layer. One exposed row costs 2,097,152 bytes/layer or **62,914,560 bytes across thirty layers** if a single logical row must be retained in all layers; a save and eventual consume imply 125,829,120 logical transfer bytes across the thirty layers before metadata or scheduling. The native 31+1 split recorded in [the singleton map receipt](qwen-moe-gdn-singleton.md) reads/writes rows 1–31 in the first call and row 0 in the second, both identity source maps, so `E=∅` and its 248,320-word divergent head **cannot be repaired by adding a cross-segment old-source snapshot**. That narrows its next diagnostic to the first divergent operand/state layer in the *unchanged graph topology*. For a future reordered segmented request with nonempty E, the construction gives the precise snapshot budget and shows why applying the unsplit source-owned theorem independently to each call is unsound. No GPU, runtime or service changed.
