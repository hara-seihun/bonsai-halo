# Routed down operands do not share native Q8 blocks

The eight routed down projections in Qwen3.6-35B-A3B consume distinct post-SwiGLU vectors. One tempting exact implementation is to intern equal quantized activation blocks across those experts and reuse their prepared operands. The real layer-0 captures close that particular route. Across 126 held tokens there are 16,128 Q8_1 blocks, with **zero identical 32-code blocks among the eight experts of any token**, whether blocks retain their K position or receive a free per-token permutation. The 113 train tokens also have zero. Thus no full native block can be shared in this observed workload even if lookup, remapping and fanout cost nothing.

| Captured split | Routed tokens | Q8_1 down blocks | Co-position expert pairs | Equal 32-code pairs | Equal codes with free block permutation | Largest pairwise coordinate agreement |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Train | 113 | 14,464 | 50,624 | 0 | 0 | 22/32 |
| Held | 126 | 16,128 | 56,448 | 0 | 0 | 24/32 |

The experiment applies the installed `quantize_q8_1` code rule to the captured finite FP32 hiddens: each group of 32 uses its own maximum divided by 127 and rounds its 32 quotients. Matching codes are a *necessary*, not sufficient, condition for sharing a byte-identical Q8_1 block. Native blocks also contain an FP16 scale and an FP16 sum of original input floats, so this test is generous to sharing. The capture has no all-zero block. Two of 56,448 held expert-pair comparisons agree on at least 24 coordinates, neither on all 32. A hypothetical partial-code dictionary would need new labels, a new consumer and its own online work; it is not an exact reuse of the current block.

One token has 8 × 16 × 36 = 4,608 bytes of these down activation blocks per layer, or 184,320 bytes across forty layers if each layer resembles layer 0. Even the impossible free collapse of every block onto a single expert's blocks saves at most 161,280 bytes, 0.00614% of the conditional 2,626,187,904-byte one-read whole-model weight stream. This comparison concerns operand bytes, not actual DRAM loads or elapsed time; it does not price quantizer instructions or claim that activation storage is streamed from DRAM once. In the actual observed captures, an equal-block interning scheme has zero byte or quantizer-block reuse before its own cost. The installed grouped gate/up path *does* share one producer activation across experts; this negative applies only to the different post-SwiGLU down inputs. Nothing here rules out a jointly designed code for the weighted expert sum or an approximation that changes those hiddens and pays for its quality.

It hashes the two input hiddens, routed IDs, source, native quantizer, capture provenance, selected runtime receipt and model acquisition. No GPU run, runtime change, new model image or serving change occurred.
