# Actual Qwen Q4 routed gate/up code-sharing ceiling

[Kelana's forty-layer real-route census](../../kelana/research/moe/code-sharing-all-route/README.md) measures identical same-position Q4_K gate/up code fragments across eight selected experts on disjoint 64-token train/held native callback routes at **every layer**. At the most generous four-byte granularity, free sharing removes at most **114,356.375 low-code bytes/token / 0.00435446%** of the conditional 2,626,187,904-byte complete one-read weight stream on held routes. **99.8547%** of those repetitions are in layer zero. Eight-byte reuse drops to 13,282.125 bytes/token / 0.000505757%; no full 144-byte Q4_K block repeats within any of the 5,120 observed eight-expert route cases in either split. The previous layer-0 synthetic-route observation was not representative of the forty-layer workload.

This is an optimistic direct identical-byte reuse grammar: equal gate/up input coordinates make same-K fragments plausible shared integer-dot operands, but the count ignores differing Q4 metadata, lookup, scatter, synchronization and native FP32 folding. The bytes are logical code uses, not measured DRAM traffic or TPS; zero full blocks applies only to these finite prompt routes. Native `mul_mat_id` already groups experts and prepares shared gate/up inputs. Do not install a frozen-code fragment dictionary to chase this ceiling. A changed learned packed image must pass broad actual-producer complete-model language loss, paid rate and a timed direct consumer. Separately, ordinary Q8/expert graph-on full-head physical-time work remains open. No model, executable, default, GPU or service changed.
